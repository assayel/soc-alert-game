# لعبة المحلل الأمني: احمِ الشبكة

لعبة تعليمية بسيطة تحاكي عمل محلل في مركز عمليات أمنية (SOC): تصلك تنبيهات SIEM عشوائية، وعليك أن تصعّد التهديد الحقيقي وتتجاهل النشاط العادي قبل انتهاء الوقت.

## التشغيل
افتح الملف `index.html` في أي متصفح. لا يحتاج تثبيتاً ولا خادماً.

## ملاحظة
المحاكاة تعليمية ولا تنفّذ أي فحص أو هجوم حقيقي على أي شبكة.
